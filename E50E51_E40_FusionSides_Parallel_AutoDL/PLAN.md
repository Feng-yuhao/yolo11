## 决策及证据等级

- 首选：E50，保留上一份复盘指定的原网格联合核生成，只改变P3 donor的上采样构建。
- 探索搭档：E51，完整E40 + 融合前P2 lateral值的自适应局部对比残差。
- 两项独立，不做E50+E51组合；共同父体为完整E40。
- E51证据弱于E50，只有明确的操作/文献依据，没有本项目已确诊的边界模糊根因。
- 不为了双开再增加第三项，不重新开启通道门控/读出/窗口关系/任务私有编码搜索。
- 如果优先论文可重复证据而不是两项结构探索，E41 seed3是更直接的复核任务：其已有两seed正收益，
  但两seed均没有超过E40；复核不是新的精度改进。不能把它强推为用户要的新增收益。

## E51 固定操作

B = model2的backbone-P2(C128,stride4)，C = model16的neck-P3(C128,stride8)。
仅改变送入Concat24的B副本，不改变model2保存在网络中的原张量或backbone后续值路径。
原model23 nearest donor保持，Concat通道次序保持，C3k2 25/完整E40/Detect保留。

核描述使用与E50同类的两路128→32压缩和各自原网格局部处理，再对齐合并，产生[B,9,H4,W4]核。
每个位置的权重跨128通道共享，softmax归一化；不加另一套channel/spatial gate。

```text
w_j(B,C) = softmax(联合原网格核描述)_j
A(B)(p) = sum_j w_j(p) * B(p+offset_j)       # 3×3，replicate边界
D(B)(p) = B(p) - A(B)(p)
B'(p) = B(p) + tanh(gain) * D(B)(p)          # gain=0
Concat24 = Concat(nearest(C), B')
```

常量B时D(B)=0，即局部残差核系数和为0；FP32计算需检查数值误差。
原B值主项保留；没有原图新像素、P1、offset采样、新监督或分数校准。
有符号gain和内容变化的核意味着整体不是固定线性纯高通，不能声称一定增强边界而不增强噪声。

## 与历史实验的真实差异

| 已做实验 | 此次差异与重叠边界 |
|---|---|
| E10 DSSG | 高频幅值是语义门控的描述量；本项直接处理P2 lateral邻域值。仍与语义/细节融合主题有重叠。 |
| E16 TSDR | 固定Gaussian高通P1、PixelUnshuffle、tiny辅助监督、仅回归注入；本项动态P2值、融合前、两任务正常监督。不能说历史从未做过高通。 |
| E35 PKI | 主干Bottleneck内大核分支混合；本项保留全部原主干路径，只改变一个lateral副本。 |
| E39 / E46 | 回归塔局部/远程残差或额外窗口关系；本项不增加头内上下文编码。 |
| E42–48 | 改路由、深度复用或读出；本项完整保留E40编码库和路由。 |
| E49 / E50 | 对粗P3 donor值进行重组；本项保持nearest donor，处理浅P2值。 |

操作位置不同不等于因果正交，也不保证两个模块能够相加。

## 文献与创新边界

FreqFusion的AHPF已有“单位核减归一化局部核”的细节残差：
https://arxiv.org/abs/2408.12879
https://github.com/Linwei-Chen/FreqFusion/blob/main/FreqFusion.py

其完整方法包含ALPF、AHPF和offset，有COCO检测结果；相关AHPF组件消融来自ADE20K分割。
不能拿完整方法成绩证明单独AHPF放入YOLO11-P2有效。
FADE也强调粗细两侧的利用：https://arxiv.org/html/2207.10392v2
CARAFE已有按位置、跨通道共享重组核：https://arxiv.org/abs/1905.02188

本项借鉴这些算子，不能宣称新的高通或重组原理。可讨论的是面向完整E40的受控路径适配及实测贡献。
若没有独立收益，仅改名/换位置不构成论文性能贡献。

## 为什么值得探索、为什么可能失败

可检验问题：保留nearest coarse donor与完整E40时，只改变fine lateral的局部对比残差，
能否得到相对E40的净AP改善？它测试融合另一侧，不用E49的几何亏损来假定已知根因。

风险：背景纹理同样带高频；动态局部均值可能扰动细小/拥挤目标；Concat+C3k2/E40可能已利用这些信息。
只有特征变化、参数更新、raw coverage改善都不能算成功；正式官方AP/AP50/AP75是主要判据。

## 训练与判断

两者均原始预训练重新训练640/batch16/workers8/seed1/200轮，公共E40初始化固定40001。
不读E40/E49 best作为训练初始化，不同时改loss/TAL算法/分类解码/NMS/数据协议。
主要对照现有E40 seed1，累计收益另列E1；E50同时与E49比较构建方式。
至少E40+0.25pp AP且AP50/AP75不下降才进入配对seed2复核；这是预算线，不是统计或发表承诺。
只有一项通过就复核它，不自动合并；两项均通过且收益复核后才考虑A+B交互实验。

## 并行工程边界

现有E49是28GiB单开包，不能直接双开沿用旧凭据。
新的并行包要按固定每进程分配上限重做真实同时batch16更新与batch32全548图验证smoke，
与formal上限和参数一致；settings、日志、锁、报告、凭据完全隔离。
不可因OOM静默降batch/分辨率或变日程；若失败保持配置串行。
P2完整FP32 unfold的[B16,C128,9,H160,W160]邻域单张约1.76GiB，应有界累加并对照独立oracle。
内存实现改善不能冒充更高精度，资源预算不能仅由参数量判断。

旧E40/E41 seed2并行约12.25小时；E40S3/E47S1并行约14.9/16.8小时，之后还有评分。
两项一起跑不保证睡醒就完成；ETA必须按新包实测速率更新。
一个子任务失败不杀另一个；评分失败保留训练权重单独补评，不重训或假称完成。
