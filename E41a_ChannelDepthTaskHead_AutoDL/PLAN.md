# E41a 通道—深度任务分解检测头

父模型 E1-640 seed1；640 / batch16 / 200epochs。原 yolo11s.pt 迁移，非 E1 best 微调。
与 E40 独立训练，不读取 E40 权重。P2/P3 分别维护一套模块，P4/P5 原检测头输入保持原样。

每个模块：Conv1x1(128,48)+GN(6)+SiLU，三个连续 Conv3x3(48,48)+GN(6)+SiLU。
保存四个深度 Z0..Z3，concat192 -> GAP -> Conv1x1(192,32,no bias) -> SiLU -> Conv1x1(32,384,bias)。
reshape [B,2,4,48,1,1]，沿四深度轴做 softmax。任务0=分类，任务1=回归。
每个任务和通道独立加权四深度；池化只生成权重，实际空间特征始终完整保留。
两个独立、零初始化 Conv1x1(48,128,no bias) 生成残差，分别加回原 X，进入原 cv3/cv2。

原 cv2/cv3、DFL、解码、TAL算法、损失、NMS保留，基础网络联合训练。
实际预测变化可能改变 TAL 匹配；不宣称训练轨迹或所有参数更新等于 E1。
新增199680参数，路由参数图像相关而非静态alpha。E40则在空间位置上选深度、共用通道权重。
沿用40001分支初始化种子并保护全局CPU/CUDA RNG；不能声称E40/E41所有新增权重逐项相同。

已有文献：TOOD https://arxiv.org/abs/2108.07755；作者实现
https://github.com/fcjian/TOOD/blob/master/mmdet/models/dense_heads/tood_head.py 。
本实验是增量改造，不是完整TOOD复现，不主张首次任务/通道注意力。
全局统计被背景主导是明确风险。现有 raw 高IoU不足不是任务冲突根因证明。

主比较：官方 AP/AP50/AP75 相对 E1 seed1；完整548图，官方ignore规则。
沿用预算筛选线AP>=+0.50pp、AP75>=+0.30pp、AP50不退；不是显著性或论文录用标准。
期望新增创新部分有可重复收益，不把P2已有贡献算作本模块贡献。
完整200轮，无20/90轮性能探针；工程smoke不复用权重。

运行方式：独立check -> 独立smoke -> queue。用户明确授权：E40成功或失败都允许接续。
E40失败只记录，E40 run/eval进程和GPU仍活动时等待；GPU连续两次空闲才启动一次。
不依赖E40成功评分、完整200轮或特定旧控制器锁存在。启动前再次验证E41门禁。
正式训练未施加显存上限；smoke为12GiB上限、4GiB其他任务余量。
