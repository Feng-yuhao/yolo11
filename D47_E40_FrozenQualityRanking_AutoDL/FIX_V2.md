# D47 训练标注读取修复

原 check 失败发生在读取训练标注阶段，尚未缓存候选或拟合排序器。
原因是训练集有零高度 class-0 ignore 行，原先错误地直接复用了严格验证集解析器。

现在仅替换 train loader：class-0 的零宽/零高行保留原数值，使用冻结官方 coverage helper 已有的 raster 查询语义，并记录完整行号、数值与计数。禁止负尺寸、非法/非整数类别和零尺寸非 class-0 框。不改原始数据。

验证集 d27_official.py、E40 结构文件、排序器输入/网络/损失/日程和官方评价协议未改。正常标注的读取记录与原 loader 逐数组、逐 metadata 字段一致。

代码指纹变化，必须重新执行 check、smoke、verify-gates，再运行 run。旧凭据不可跳过。
本地测试不代替服务器全训练集扫描；遇到其他非法标注仍显式报错，不自动删除。
